# manga_renamer

面向本地漫画库的批量整理工具，主要用于校正漫画名称，支持人工确认、AI 复核，以及文件夹和压缩包的批量改名与移动。

## 关于这个项目

本工具百分之百由 GPT“许愿编程”创作。本人完全不懂代码，只是多年来下载的 E 站漫画名称总有各种毛病，想尽量校正，却一直苦于没有顺手的批量处理工具。如今幸得神兵利器，才有此拙作。

作者目前可用于测试的设备和环境有限，主要由 GPT 自行运行测试，尚未进行大批量真机验证。使用前请先备份重要数据，并用少量漫画试跑，确认改名、移动和撤销符合预期后再扩大范围。

希望它也能帮到有同样需求的人。若有不足，欢迎反馈。

## 命名规则与示例

本工具尝试将本地漫画名称整理为符合 E-Hentai / ExHentai 原版标题习惯的格式，补全可确认的社团、画师、标题和原作信息，修正字段缺失、顺序混乱等问题。

基本格式：

```text
[社团名 (画师名)] 作品名称 (原作名称) [语言] [状态]
举例：
[かうすしあん (やまいそ)] 感度良好十六夜咲夜 (東方Project) [中国翻訳] [DL版]

[画师名] 作品名称 (刊物名称及期号) [语言] [状态]
举例：
[ガー] 図書室の蠧魚 (COMIC 快楽天ビースト 2023年3月号) [中国翻訳] [DL版]
```

以上格式为名称整理的参考目标。基础名称整理仅使用数据库已有字段尝试拼接名称，并保留作品的语言、汉化及其他必要标记，不保证信息完整或结果完全正确，仍需人工审查。主要作用是集中展示名称建议与相关信息，减少来回翻页、逐项查找的麻烦。

## 功能

- **名称整理**：结合漫画管理器数据库与本地名称生成建议，支持手动编辑、分类、搜索和冲突检查。
- **AI 复核**：通过 API 直接送审，或导出 TXT 交给外部 AI 审核，再导入结果。
- **批量改名**：支持漫画文件夹及 ZIP、RAR、7Z、CBZ、CBR 压缩包整体改名。
- **批量移动**：支持本地同盘、跨盘移动；跨盘复制后校验文件内容，再清理源文件。
- **任务管理**：支持队列、暂停、继续和中断后恢复。
- **撤销操作**：可分别恢复原名、移回原处，或组合撤销。

## 环境要求

- Windows。
- Python 3.11 或以上版本。
- 首次启动需要联网安装依赖。
- 已使用 [exhentai-manga-manager](https://github.com/SchneeHertz/exhentai-manga-manager)（ExHentai 本地漫画标签管理阅读应用）建立漫画库，并准备好它生成的 **`database.sqlite`** 数据库文件及对应的本地漫画目录。

`database.sqlite` 在免安装版中位于漫画管理器的程序根目录，安装版通常位于 `%APPDATA%\exhentai-manga-manager\`。

API 复核需要自行配置接口、模型和密钥；TXT 复核可通过外部 AI 工具完成。

## 安装与启动

1. 下载项目源码或完整发布包，解压到可写目录。
2. 安装 Python，勾选 **Add Python to PATH**。
3. 双击根目录的 `run.bat`。

首次启动会自动创建 Python 虚拟环境并安装依赖，后续启动会复用该环境。

也可以在项目根目录通过命令行启动：

```sh
python -m pip install -r requirements.txt
python -m src.main
```

## 使用方法

### 整理名称

1. 选择漫画管理器的 `database.sqlite` 和本地漫画目录，开始扫描。
2. 查看当前名称、建议名称和判断依据，通过分类或搜索缩小范围。
3. 按需手动修改、人工确认，或交给 AI 复核。
4. 勾选需要处理的漫画，在操作预览中确认名称与路径，再执行改名或移动。

### AI 复核

- **API 模式**：填写接口、模型和密钥，选择送审范围后运行，查看并确认返回的名称建议。
- **TXT 模式**：导出待审核文件及规则资料，交给外部 AI 审核；获得结果 TXT 后导入工具，检查并应用建议。

支持补充判断依据，以及继续处理任务中的剩余项。

### 移动与撤销

移动任务按提交顺序执行，可在任务页暂停或继续。关闭任务窗口不会停止执行；退出主程序后，未完成任务会保留，重新启动后可手动继续。

撤销提供三种方式：

- **恢复原名**：保留当前位置，恢复原来的名称。
- **移回原处**：保留当前名称，返回原来的位置。
- **组合撤销**：同时恢复名称与位置。

## 数据与更新

程序运行时会在项目目录中生成以下文件夹：

| 目录 | 用途 |
| --- | --- |
| `data/` | 设置、会话、任务记录和恢复状态 |
| `logs/` | 运行与任务日志 |
| `runtime/` | 启动脚本创建的 Python 虚拟环境 |

更新前先关闭程序。用新版程序文件覆盖旧版，保留 `data/`；需要保留日志时同时保留 `logs/`。

迁移到新目录时，请复制整个 `data/`，并在新位置重新创建 `runtime/`。存在未完成的移动任务时，请保留目标盘上的 `.manga-transfer-*` 临时对象，以便继续任务。

## 使用限制

- 当前需要漫画管理器数据库，独立获取漫画名称属于后续计划。
- 压缩包按完整文件处理，不修改包内文件名称。
- 移动遇到同名目标时，不覆盖或合并已有内容。
- 当前不支持网络目录、映射网络盘，以及符号链接、联接或重解析点的真实移动。
- AI 建议需结合预览与判断依据进行确认。

## 常见问题

**双击启动后没有打开窗口怎么办？**

运行 `scripts/debug_run.bat` 查看报错，相关日志位于 `logs/`。如果 Python 环境损坏，可以关闭程序后删除 `runtime/`，再运行 `run.bat` 重建；请保留 `data/`。

**界面布局异常怎么办？**

尝试运行 `scripts/safe_layout_run.bat`，使用安全布局启动。
